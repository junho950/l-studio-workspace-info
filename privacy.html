접근하는 Google 정보와 사용 목적

사용자가 승인한 Google 계정의 기본 캘린더 ID·이름을 확인하고, 일정의 제목·날짜·시간·설명과 편집 충돌 확인에 필요한 식별자·버전을 사용합니다. 캘린더 목록 읽기와 일정 관리 권한을 요청하며, 앱의 동작은 본인 기본 캘린더로 제한합니다.

조회한 일정은 달력·대시보드 표시와 원본 수정에 사용합니다. 새 일정을 만들 때 Notion 장부의 원본 ID를 먼저 예약하고 Google 캘린더에 등록합니다. 앱에서 직접 만든 일정은 편집 시 연결된 Notion 행에도 반영합니다. 기존 Google 일정의 조회 목록 전체를 Notion에 자동 복사하지 않습니다.

저장과 외부 전송

일정 조회 캐시와 연결 식별자는 사용자 PC의 앱 데이터 폴더에 저장합니다. Google OAuth 설정과 토큰은 Windows 현재 사용자 계정으로 암호화 저장합니다. 일반 JSON 자료 내보내기에 Google 토큰은 포함하지 않습니다.

일정 조회·추가·수정·취소에 필요한 요청은 Google API로 전송합니다. Notion에 연결된 새 일정과 해당 일정의 변경은 사용자가 연결한 Notion 장부로 전송합니다. 기존 Muse·Pickle 연결을 통해 Notion 자료를 사용하는 동작은 사용자가 각 서비스에 설정한 권한과 정책을 따릅니다.

공개 안내 웹사이트에는 일정·기록·인증 정보를 전송하지 않습니다. 이 앱은 Google 사용자 자료를 광고, 판매 또는 범용 AI 모델 학습 목적으로 사용하는 기능을 제공하지 않습니다. Google API에서 받은 정보의 사용과 전송은 Google API Services User Data Policy의 Limited Use 요구사항을 따릅니다.

연결 해제와 자료 관리

앱 설정에서 Google 연결을 해제하면 로컬 Google 토큰을 제거하고 Google 일정 표시를 중단합니다. 로컬 조회 캐시와 이미 저장한 Notion 자료, Google 원본 일정은 연결 해제만으로 삭제하지 않습니다. Google 계정의 서드 파티 연결 관리에서도 접근 권한을 철회할 수 있습니다.

PC에 남은 자료와 백업은 사용자가 관리합니다. 일정을 구글에서 취소하거나 Notion 자료를 보관하는 기능은 해당 화면에서 명시적으로 실행합니다. 여러 날·초대·특수 일정 등 앱에서 직접 편집할 수 없는 항목은 Google 원문에서 관리합니다.
